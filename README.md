# 🤖 Robot Signal Extractor (Web Version)

A professional industrial tool to extract DI/DO signals from robot backup files (.LS) and generate formatted Excel tables.

## 🚀 Features

-   **Web-Based Interface**: No installation required.
-   **Zip Upload**: Drag and drop your robot backup folder (zipped).
-   **Consolidated Excel**: Automatically creates sheets for each robot found in the backup.
-   **Signal Logic**: Detects both comments and logic states (ON/OFF).

## 🛠️ Deployment Instructions (GitHub + Streamlit Cloud)

To host this tool for free, follow these steps:

1.  **Create a New Repository** on GitHub.
2.  **Upload the following files** to the repository:
    -   `app.py`
    -   `requirements.txt`
    -   `README.md`
3.  **Go to [Streamlit Cloud](https://share.streamlit.io/)**.
4.  **Connect your GitHub account** and select your new repository.
5.  **Click "Deploy!"**.

Your web tool will be live in minutes!

## 📦 Requirements
